Starting November 24, Quad9 stops to answer to French IP addresses.  
If your server is located in France you have to edit your AdGuard Home configuration to remove [Quad9 resolvers](https://quad9.net/service/service-addresses-and-features/) and optionnaly add new ones.

---

We are proposing those services, provided by friend structures of YunoHost, to replace Quad9:

[Alsace Réseau Neutre](https://arn-fai.net/fr/internet-alternatif/dns):

- IPv4: `89.234.141.66`
- IPv6: `2a00:5881:8100:1000::3`

[Aquilenet](https://dns.aquilenet.fr):

- IPv4: `45.67.81.23`
- IPv6: `2a0c:e300::1337`
- DoH: `https://dns.aquilenet.fr/dns-query`

[La Contre-Voie](https://lacontrevoie.fr/services/doh/):

- DoH: `https://doh.lacontrevoie.fr/dns-query`

[French Data Network (FDN)](https://www.fdn.fr/actions/dns/):

- IPv4: `80.67.169.12` `80.67.169.40`
- IPv6: `2001:910:800::12` `2001:910:800::40`
- DoH: `https://ns0.fdn.fr/dns-query` `https://ns1.fdn.fr/dns-query`

---

You can use this snippet as a reference to fix your configuration:

```yaml
  upstream_dns:
    - https://doh.lacontrevoie.fr/dns-query
    - https://ns0.fdn.fr/dns-query
    - https://ns1.fdn.fr/dns-query
    - https://dns.aquilenet.fr/dns-query
  upstream_dns_file: ""
  bootstrap_dns:
    - 89.234.141.66
    - 45.67.81.23
    - 80.67.169.12
    - 80.67.169.40
    - 2a00:5881:8100:1000::3
    - 2a0c:e300::1337
    - 2001:910:800::12
    - 2001:910:800::40
```

Your configuration is located at `__INSTALL_DIR__/AdGuardHome.yaml`.
